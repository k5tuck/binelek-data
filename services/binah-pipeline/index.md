# Binah Pipeline - API Documentation

Welcome to the Binah Pipeline API documentation.

## Overview

The Binah Pipeline Service manages data processing pipelines and ETL workflows for the Binelek platform.

## API Reference

For detailed API documentation, see the [API Reference](api/index.md).

## Architecture

The service is built with:
- **.NET 8.0** - Modern C# web API
- **ASP.NET Core** - Web framework
- **Prometheus** - Metrics and monitoring
