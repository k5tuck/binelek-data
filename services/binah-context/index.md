# Binah Context - API Documentation

Welcome to the Binah Context API documentation.

## Overview

The Binah Context Service provides semantic context management and graph enrichment for entities in the Binelek platform.

## API Reference

For detailed API documentation, see the [API Reference](api/index.md).

## Architecture

The service is built with:
- **.NET 8.0** - Modern C# web API
- **ASP.NET Core** - Web framework
- **Prometheus** - Metrics and monitoring
