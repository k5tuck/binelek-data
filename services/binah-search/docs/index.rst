Overview
--------

The Binah Search service provides semantic search and vector similarity
capabilities for the Binelek platform.

Key Features
~~~~~~~~~~~~

* **Semantic Search** - AI-powered search with embeddings
* **Vector Similarity** - Find similar entities and documents
* **Index Management** - Create and manage search indices
* **FastAPI Framework** - Modern async Python web framework
* **Multi-tenant Support** - Isolated search indices per tenant
* **Real-time Indexing** - Kafka-based event streaming

Architecture
------------

The service is built with:

* **Python 3.11** - Modern Python runtime
* **FastAPI** - Async web framework
* **Kafka** - Event streaming
* **Elasticsearch/Vector DB** - Search and vector storage
* **Redis** - Caching layer
